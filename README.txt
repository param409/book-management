BOOK MANAGEMENT - SPRING MVC + THYMELEAF

Requirements:
- Java 17 or later
- Maven

Run:
1. Extract this ZIP.
2. Open a terminal in the extracted book-management-spring-mvc folder.
3. Run: mvn spring-boot:run
4. Open http://localhost:8080/books

Features:
- List books
- Add a book
- Delete a book
- Home page redirects to /books

Note: Book data is stored in memory and resets when the application restarts.
